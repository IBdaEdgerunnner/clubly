Clubly (CampusConnect) – Student Club & Association Portal

Clubly (CampusConnect) is a web-based platform designed to simplify how students discover, join, and interact with clubs and associations within their institution.

The platform provides students with an easy way to explore available clubs, submit membership requests, and stay updated on announcements and upcoming events. Club administrators can manage membership requests and publish information relevant to their clubs.

Student Features

- Browse available clubs and view club information.
- Submit membership requests.
- Track membership request statuses.
- View joined clubs.
- Access announcements and upcoming events.
- Manage account sessions.

Club Administrator Features

- Dedicated administrator dashboard.
- View and manage membership requests.
- Approve or decline membership applications.
- Track membership activities.
- Publish announcements.
- Create and publish events.
- View club-related information.

Technologies Used

- HTML5 – Page structure.
- JavaScript – Application logic and interactivity.
- Tailwind CSS – Styling and responsive layouts.
- Firebase Authentication – User registration and authentication.
- Cloud Firestore – Cloud database and application data storage.

Backend Architecture

Clubly (CampusConnect) uses Firebase as its Backend-as-a-Service (BaaS) platform.

Firebase Authentication handles user authentication, while Cloud Firestore stores and retrieves application data, including user profiles, membership requests, announcements, and events.

Project Structure

The project consists of separate pages for students, club administrators, club discovery, club information, announcements, and events, alongside shared JavaScript and styling resources.

Deployment

The application is deployed as a web-based platform and uses Firebase services for authentication and database operations.

Project Purpose

Clubly (CampusConnect) was developed as a student project to demonstrate practical web development skills, frontend development, database integration, user authentication, and the implementation of dynamic application workflows.
